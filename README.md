# Projeto Sessão Mobile

## Sobre o projeto

O **Sessão Mobile** é um projeto desenvolvido para fins de estudo, com o objetivo de praticar o desenvolvimento de aplicações web utilizando Java e Spring Boot.

A aplicação utiliza uma estrutura organizada em camadas para trabalhar com os dados de sessões de dispositivos móveis.

## Tecnologias utilizadas

- Java 17
- Spring Boot
- Spring Data JPA
- SQLite
- HTML

## Funcionalidades

- Cadastro de informações de sessões.
- Consulta e listagem de registros.
- Persistência de dados utilizando SQLite.

## Estrutura do projeto

- `controller`: responsável por receber e tratar as requisições da aplicação.
- `model`: contém a representação dos dados utilizados.
- `repository`: responsável pelo acesso e pela persistência dos dados.
- `templates`: contém as páginas HTML da aplicação.

## Como executar o projeto

1. Instale o Java 17 ou uma versão compatível com o projeto.
2. Clone este repositório.
3. Importe o projeto em uma IDE compatível, como o Eclipse.
4. Aguarde a resolução das dependências do Maven.
5. Execute a classe principal `SessaomobileApplication`.
6. Acesse o endereço local configurado pela aplicação no navegador.
